# 클래스 티어 — 학급 생활 종합 티어

오목 아레나의 티어 시스템을 학급 운영용으로 옮긴 앱입니다. 수행평가·학급 대회·칭찬·독서·과제·1인1역을 모아 **매달** 티어를 정하고, 월말에 티어별 보상을 안내합니다.
서버 없이 GitHub Pages(화면) + Firebase(데이터)로 동작합니다. 한 반(선생님 1명 + 학생 최대 25명)용입니다.

---

## 1. 점수 규칙

### 한 달 = 한 시즌
- 매달 1일 모두 **1000점**에서 새로 시작
- 월말에 선생님이 **「월 마감」** → 그달 티어·순위·보상 확정, 명예의 전당 기록
- 이름 앞 엠블럼 = **지난달 확정 티어**(보상 기준), 내 화면 = **이번 달 현재 점수·예상 티어**(실시간)

### 경쟁 항목 (수행평가, 학급 대회·경쟁활동) — 입력 방식 3가지

| 입력 방식 | 점수 계산 |
|---|---|
| **등급** (매우잘함·잘함·보통·노력요함) | 절대평가: 활동의 **기준 점수** × 매우잘함 100% · 잘함 50% · 보통 0% · 노력요함 −50% (비율은 설정에서 변경) |
| **점수** + 기준 점수 | 기준보다 높으면 오르고, 낮으면 내려감. 크기는 반에서 기준과 가장 멀리 떨어진 학생이 최대(±변동 폭), 나머지는 거리에 비례. 상대 보정 적용 |
| **점수**(기준 없음) / **순위** | 아래의 순수 상대평가 |

예) 기준 점수 40인 등급 평가: 매우잘함 +40, 잘함 +20, 보통 0, 노력요함 −20
예) 기준 80점, 변동 폭 보통(±40), 모두 1000점일 때: 100점 +40, 90점 +20, 80점 0, 75점 −10, 60점 −40

**상대 보정**(점수+기준 방식): 이번 달 점수가 높은 학생은 조금 덜 오르고 조금 더 내려가며, 낮은 학생은 반대입니다(0.5~1.5배).

#### 순수 상대평가 (순위, 기준 없는 점수)
참가한 학생 모두를 1:1로 비교해 점수가 오갑니다.

```
변동 = K ÷ (참가자수 − 1) × Σ(실제 결과 − 기대 승률)
기대 승률 = 1 ÷ (1 + 10^((상대 점수 − 내 점수) ÷ 400))
```

- 모두 같은 점수일 때 1등 **+K/2**, 꼴등 **−K/2** (K: 작게 50 / 보통 80 / 크게 110 → 최대 ±25 / ±40 / ±55)
- **나보다 점수가 높은 친구보다 잘하면 더 많이 오르고**, 약한 친구에게 지면 더 많이 내려감 — 오목 티어의 상대 보정과 같은 원리
- 반 전체 점수 합은 그대로 (누가 오르면 누가 내려감)
- 빈칸 = 불참(변화 없음). 모둠 활동은 같은 모둠에 같은 순위 입력(동점 처리)

### 단원평가 — 학생이 점수 입력, 선생님 확인
「경쟁 활동」에서 종류를 **단원평가**로 만들면(점수 방식 + 기준 점수 권장) 학생 「기록하기」에 열립니다. 학생이 자기 점수를 입력 → 「승인 대기」에서 확인하면 그 활동의 결과로 합쳐져 계산됩니다. 「제출 마감」으로 입력을 닫을 수 있습니다.

### 누적 항목 — 생활 점수
| 항목 | 입력 | 기본 배점 | 월 한도 |
|---|---|---:|---:|
| 칭찬 | 선생님 | +5 (지급 때 조정 가능) | 없음 |
| 감점 | 선생님 (사유 필수) | −5 | 없음 |
| 독후감 | 학생이 이번 주 통과 O/X 제출 → 선생님 승인 (X는 0점) | +5 | 5회 |
| 과제·숙제 완료 | 학생 제출 → 선생님 승인 | +3 | 15회 |
| 1인1역·봉사 | **선생님이 날짜별로 체크** (「칭찬·1인1역」 탭) | +3 | 15회 |
| 한자 매일 학습 | 앱이 채점 (80% 이상) | +1 | 20회 |
| 타자·리코더 승급 | 학생 심사 신청 → 선생님 승인 (또는 선생님이 바로 승급) | +10 | 종목별 1회 |
| 한자 승급 | 앱 승급 시험 통과 | +10 | 1회 |

### 급수 트랙 (타자·리코더·한자)
- 타자·리코더: 선생님이 쓰던 급수표(8단계씩) 그대로. 「급수·한자」 탭에서 처음 급수를 맞추고(점수 없음), 이후 승급은 +10점
- 승급 점수는 처음 급수와 관계없이 같음 → 원래 잘하던 학생보다 **노력해서 올라간 학생**을 보상

### 한자 (7급 150자 — 한국어문회 배정한자 8급 50 → 7급Ⅱ 50 → 7급 50)
- **매일 학습**(학교에서만, 설정한 요일·시간): 새 한자 5자 카드(획순 애니메이션·따라 쓰기) → 퀴즈(새 한자 + 복습) → 80% 이상이면 완료. 틀린 한자는 다음 날, 맞힌 한자는 3·7·14일 뒤 복습
- **개인별 승급 시험**: 현재 급수 한자를 모두 배우면 응시. 문항 수로 통과 기준 결정(10문항 이하 90% · 11~29문항 80% · 30문항 이상 70%). 떨어지면 다음 날 재도전
- 문항 유형: 훈음 고르기 · 한자 고르기 · 한자어 읽기 (필순 문제 없음)
- 가정 학습 불인정: 앱 설정 시간 + 보안 규칙(평일 07:30~17:30 한국 시간)으로 이중 제한
- ※ `js/hanja.js`의 훈음·한자어는 초안이니 한 번 검토해 주세요. 敎는 획순 데이터가 없어 정지 글자로 보입니다.

한도를 넘은 기록은 0점으로 반영됩니다. 배점·한도·항목 이름은 「설정」에서 바꿀 수 있습니다.

### 티어
브론즈 ~899 · 실버 900~ · 골드 1000~ · 플래티넘 1100~ · 다이아 1175~ · **챔피언 = 그달 1위** (기준 점수는 설정에서 변경 가능)

### 자동 재계산
활동을 고치거나 지우면 **그달 전체를 처음부터 다시 계산**합니다. (오목과 달리 이후 경기 보정까지 정확히 반영)

## 2. 공개 범위 (보안 규칙으로 보장)

| 정보 | 학생 본인 | 다른 학생 | 선생님 |
|---|:---:|:---:|:---:|
| 티어·순위·총점 | ✅ | ✅ (총점은 설정에서 숨길 수 있음) | ✅ |
| 수행평가·대회 원점수, 항목별 점수 | ✅ 본인 것만 | ❌ | ✅ |
| 칭찬·감점·제출 기록 | ✅ 본인 것만 | ❌ | ✅ |

학생 기록은 학생 기기에서 점수를 바꿀 수 없습니다. 점수 계산은 선생님 화면에서만 이뤄지고, 학생은 "대기" 상태의 기록만 제출할 수 있습니다.

## 3. 선생님 화면

- **순위 현황**: 이번 달 순위·예상 티어·경쟁/생활 점수·승인 대기, 학생별 상세
- **승인 대기**: 학생 제출 기록 한꺼번에 승인/반려(사유), 되돌리기
- **경쟁 활동**: 수행평가·대회 결과 입력, 저장 전 **변동 미리보기**
- **칭찬·감점**: 학생 여러 명 선택 → 한 번에 지급
- **학생 관리**: 등록(일괄), 비밀번호 확인/변경, 이름 변경, 삭제
- **월 마감·보상**: 티어별 보상 문구 설정, 월 마감(승인 대기가 남아 있으면 마감 불가), 학생별 보상 **지급 체크**, 마감 취소
- **설정**: 항목 배점·월 한도, 티어 기준, 총점 공개 여부, 반 이름, 비밀번호

## 4. 학생 화면 (태블릿·휴대폰)

홈(이번 달 점수·예상 티어·지난달 보상) · 순위 · 기록하기(독서/과제/1인1역) · 내 점수(항목별 내역) · 명예의 전당

## 5. 설치

1. **데모로 체험**: `.\serve.ps1` 실행 → `http://localhost:8767` (Firebase 없이 이 브라우저에만 저장)
2. **Firebase** (오목 아레나와 **별도 프로젝트**): Authentication 이메일/비밀번호 사용 설정 → Realtime Database 생성(싱가포르) → 규칙 탭에 `database.rules.json` 게시 → 웹 앱 등록 후 설정값을 `js/firebase-config.js`에 입력
3. **GitHub Pages**에 올리고, Firebase 승인된 도메인에 `아이디.github.io` 추가
4. 처음 접속 → 선생님 계정(아이디 `teacher`) 만들기 → 학생 등록

```
index.html              화면 구조

js/tier.js              점수 엔진 (상대평가·누적·월 한도·티어·순위)

js/hanja.js             한자 150자 자료 (훈음·대표 한자어)
js/hanja-study.js       학생 한자 학습·승급 시험
js/app.js               로그인·공용 UI·학생 화면

```
