# 클래스 티어 — 학급 생활 종합 티어 + 학급 경제

오목 아레나의 티어 시스템을 학급 운영용으로 옮긴 앱입니다. 수행평가·학급 대회·칭찬·독서·과제·1인1역을 모아 **매달** 티어를 정하고, 월말에 티어별 보상을 안내합니다.
여기에 수페(soopeh)에서 쓰던 **학급 경제**(보내기·받기, 상점, 예금, 주식, 직업·급여·소득세, 통계)를 합쳤습니다.
서버 없이 GitHub Pages(화면) + Firebase(데이터)로 동작합니다. 한 반(선생님 1명 + 학생 최대 25명)용입니다.

화면은 위쪽 **영역**(🏠 학급 홈 · 🏆 티어 · 💰 경제 · 🎯 퀘스트 · 📌 판 · ⚙️ 관리)과 아래쪽 **탭**으로 나뉩니다.

## 1. 점수 규칙

### 한 달 = 한 시즌
- 매달 1일 모두 **1000점**에서 새로 시작
- 월말에 선생님이 **「월 마감」** → 그달 티어·순위·보상 확정, 명예의 전당 기록
- 이름 앞 엠블럼 = **지난달 확정 티어**(보상 기준), 내 화면 = **이번 달 현재 점수·예상 티어**(실시간)

### 경쟁 항목 (수행평가, 학급 대회·경쟁활동) — 입력 방식 3가지

| 입력 방식 | 점수 계산 |
|---|---|
| **등급** (매우잘함·잘함·보통·노력요함) | 절대평가: 활동의 **기준 점수** × 매우잘함 100% · 잘함 50% · 보통 0% · 노력요함 −50% (비율은 설정에서 변경) |
| **점수** + 기준 점수 | 기준보다 높으면 오르고, 낮으면 내려감. 크기는 반에서 기준과 가장 멀리 떨어진 학생이 최대(±변동 폭), 나머지는 거리에 비례. 상대 보정 적용 |
| **점수**(기준 없음) / **순위** | 아래의 순수 상대평가 |

예) 기준 점수 40인 등급 평가: 매우잘함 +40, 잘함 +20, 보통 0, 노력요함 −20
예) 기준 80점, 변동 폭 보통(±40), 모두 1000점일 때: 100점 +40, 90점 +20, 80점 0, 75점 −10, 60점 −40

**상대 보정**(점수+기준 방식): 이번 달 점수가 높은 학생은 조금 덜 오르고 조금 더 내려가며, 낮은 학생은 반대입니다(0.5~1.5배).

#### 순수 상대평가 (순위, 기준 없는 점수)
참가한 학생 모두를 1:1로 비교해 점수가 오갑니다.

```
변동 = K ÷ (참가자수 − 1) × Σ(실제 결과 − 기대 승률)
기대 승률 = 1 ÷ (1 + 10^((상대 점수 − 내 점수) ÷ 400))
```

- 모두 같은 점수일 때 1등 **+K/2**, 꼴등 **−K/2** (K: 작게 50 / 보통 80 / 크게 110 → 최대 ±25 / ±40 / ±55)
- **나보다 점수가 높은 친구보다 잘하면 더 많이 오르고**, 약한 친구에게 지면 더 많이 내려감 — 오목 티어의 상대 보정과 같은 원리
- 반 전체 점수 합은 그대로 (누가 오르면 누가 내려감)
- 빈칸 = 불참(변화 없음). 모둠 활동은 같은 모둠에 같은 순위 입력(동점 처리)

### 단원평가 — 학생이 점수 입력, 선생님 확인
「경쟁 활동」에서 종류를 **단원평가**로 만들면(점수 방식 + 기준 점수 권장) 학생 「기록하기」에 열립니다. 학생이 자기 점수를 입력 → 「승인 대기」에서 확인하면 그 활동의 결과로 합쳐져 계산됩니다. 「제출 마감」으로 입력을 닫을 수 있습니다.

### 누적 항목 — 생활 점수
| 항목 | 입력 | 기본 배점 | 월 한도 |
|---|---|---:|---:|
| 칭찬 | 선생님 | +5 (지급 때 조정 가능) | 없음 |
| 감점 | 선생님 (사유 필수) | −5 | 없음 |
| 독후감 | 학생이 이번 주 통과 O/X 제출 → 선생님 승인 (X는 0점) | +5 | 5회 |
| 과제·숙제 완료 | 학생 제출 → 선생님 승인 | +3 | 15회 |
| 1인1역·봉사 | **선생님이 날짜별로 체크**, 또는 **학생이 자기 직업(역할)을 스스로 체크 → 선생님 확인** (「칭찬·1인1역」 탭에서 방식 선택) | +3 | 15회 |
| 한자 매일 학습 | 앱이 채점 (80% 이상) | +1 | 20회 |
| 타자·리코더 승급 | 학생 심사 신청 → 선생님 승인 (또는 선생님이 바로 승급) | +10 | 종목별 1회 |
| 한자 승급 | 앱 승급 시험 통과 | +10 | 1회 |

### 1인1역 = 직업
「💰 경제 → 직업·급여」에서 학생에게 준 직업이 곧 1인1역이에요. 「칭찬·1인1역」 탭 위쪽에서 체크 방식을 고릅니다.
- **선생님이 체크**: 날짜를 고르고 역할을 한 학생을 눌러 저장 (학생 카드에 직업 이름이 보임)
- **학생이 직접 체크 → 확인**: 직업이 있는 학생의 홈·직업 화면에 「🤝 오늘 역할 다 했어요!」가 생기고, 누르면 선생님 화면에 「확인 대기」로 보여요. 「학생 체크 모두 확인」 또는 고른 채 저장하면 인정(+3점), 고르지 않으면 「확인 안 함」. 하루 한 번, 오늘 날짜로만 체크할 수 있어요(보안 규칙).
- 급여 표에 학생마다 **이번 주(월~일) 1인1역 인정 날 수**가 보여요. 안 한 날만큼 깎으려면 「추가」에 −금액을 적어요.

### 급수 트랙 (타자·리코더·한자)
- 타자·리코더: 선생님이 쓰던 급수표(8단계씩) 그대로. 「급수·한자」 탭에서 처음 급수를 맞추고(점수 없음), 이후 승급은 +10점
- 승급 점수는 처음 급수와 관계없이 같음 → 원래 잘하던 학생보다 **노력해서 올라간 학생**을 보상

### 한자 (7급 150자 — 한국어문회 배정한자 8급 50 → 7급Ⅱ 50 → 7급 50)
- **매일 학습**(학교에서만, 설정한 요일·시간): 새 한자 5자 카드(획순 애니메이션·따라 쓰기) → 퀴즈(새 한자 + 복습) → 80% 이상이면 완료. 틀린 한자는 다음 날, 맞힌 한자는 3·7·14일 뒤 복습
- **개인별 승급 시험**: 현재 급수 한자를 모두 배우면 응시. 문항 수로 통과 기준 결정(10문항 이하 90% · 11~29문항 80% · 30문항 이상 70%). 떨어지면 다음 날 재도전
- 한자마다 **한자어 3~5개(총 689개)와 뜻풀이**를 보여줘 문해력 향상 (예: 車 → 자동차·차도·전차·자전거·인력거, 읽기가 바뀌는 낱말은 안내)
- 문항 유형: 훈음 고르기 · 한자 고르기 · 한자어 읽기 · **뜻 보고 낱말 고르기** (필순 문제 없음)
- 가정 학습 불인정: 앱 설정 시간 + 보안 규칙(평일 07:30~17:30 한국 시간)으로 이중 제한
- ※ `js/hanja.js`의 훈음·한자어는 초안이니 한 번 검토해 주세요. 敎는 획순 데이터가 없어 정지 글자로 보입니다.

한도를 넘은 기록은 0점으로 반영됩니다. 배점·한도·항목 이름은 「설정」에서 바꿀 수 있습니다.

### 티어
브론즈 ~899 · 실버 900~ · 골드 1000~ · 플래티넘 1100~ · 다이아 1175~ · **챔피언 = 그달 1위** (기준 점수는 설정에서 변경 가능)

### 자동 재계산
활동을 고치거나 지우면 **그달 전체를 처음부터 다시 계산**합니다. (오목과 달리 이후 경기 보정까지 정확히 반영)

## 3. 선생님 화면 (🏆 티어 · ⚙️ 관리)

**선생님 로그인**: 아이디 `teacher` + 비밀번호, 또는 **Google 계정**. 「관리 → 티어 설정 → 선생님 계정」에서 「Google 계정 연결」을 한 번 해 두면 어느 기기에서든 로그인 화면의 「Google 계정으로 로그인」으로 들어와요. (학생은 아이디·비밀번호) 새 반을 만들 때도 「Google 계정으로 시작하기」를 쓸 수 있어요. 연결되지 않은 Google 계정으로는 들어올 수 없어요.

**앱으로 설치**: 크롬에서 열면 주소창 오른쪽 설치 아이콘(또는 메뉴 ⋮ → 앱 설치)이나 로그인·홈 화면의 「📲 앱으로 설치」 버튼으로 태블릿·PC 바탕화면에 아이콘을 만들 수 있어요. iPad Safari는 공유 버튼 → 「홈 화면에 추가」. 설치해도 늘 최신 버전으로 열려요.

- **순위 현황**: 이번 달 순위·예상 티어·경쟁/생활 점수·승인 대기, 학생별 상세
- **승인 대기**: 학생 제출 기록 한꺼번에 승인/반려(사유), 되돌리기
- **경쟁 활동**: 수행평가·대회 결과 입력, 저장 전 **변동 미리보기**
- **칭찬·감점**: 학생 여러 명 선택 → 한 번에 지급
- **학생 관리**: 등록(일괄), 비밀번호 확인/변경, 이름 변경, 삭제
- **월 마감·보상**: 티어별 보상 문구 설정, 월 마감(승인 대기가 남아 있으면 마감 불가), 학생별 보상 **지급 체크**, 마감 취소
- **설정**: 항목 배점·월 한도, 티어 기준, 총점 공개 여부, 반 이름, 비밀번호

## 5. 학급 경제

### 선생님
| 곳 | 할 수 있는 일 |
|---|---|
| **🏠 학급 홈** | 학생 카드(아바타·잔액·총자산), 여러 명 골라 **보내기**(새로 만든 돈 또는 국고에서, 소득세 떼기 선택) · **받기**(없애기 또는 국고로) · **🎲 뽑기** · **🔍 자산 살피기**(잔액 고치기, 예금 지급·해지, 주식 팔아 주기, 아이템 개수, 신용 등급, 아바타, 기록) · 아이템 사용 알림 · 최근 활동 |
| **💰 경제 → 상점** | 상품 만들기(분류·가격·재고·1인 보유 한도·판매 켜기/끄기), **공동구매**(목표 금액, 모인 돈, 참여 학생, 달성 처리, 모두 환불) |
| **직업·급여** | 직업 만들기·학생 배정, **급여 보내기**: 기본급 + 급수 수당(타자·리코더 급수표의 「주급 추가」) + 추가 금액 → **소득세(설정 %)를 떼어 국고로** |
| **재테크** | 학급 증권(선생님이 가격 결정, ±% 버튼), **실제 주식 연결**(한국 종목 번호 6자리 / 미국 티커) · 투자자 · 신용 등급별 예금 현황 |
| **활동 기록** | 모든 돈·아이템 움직임 (학생·종류·검색 필터, 잔액), 아이템 사용 「처리 완료」 |
| **통계** | 7/30/60/90일: 유통 화폐(학생 총자산)·국고·발행·소각·순발행·소득세, 날짜별 막대, 발행·소각 사유, 상점 판매, 학생별 수입·지출 |
| **경제 설정** | 화폐 단위, 소득세율, 학생 메뉴 켜기/끄기, 상점 분류, 예금 기간·최소 금액·**신용 등급별 이자율**, 주식 거래 시간·하루 거래 횟수, 국고 조정 |
| **⚙️ 관리 → 수페에서 가져오기** | 아래 참고 |

티어와 연결: 타자·리코더 **승급을 승인하면 급수표의 상금**(예: 초고수 30만)을 바로 보낼 수 있고, **「주급 추가」는 급여에 급수 수당으로 자동 포함**됩니다. 「월 마감·보상」에서 티어별 **보상금**을 정해 두면 마감 뒤 한 번에 보냅니다.

### 학생 (💰 경제)
**내 지갑**(총자산·쓸 수 있는 돈·예금·주식·아이템, 아이템 사용, 내 직업과 예상 급여·세금, 거래 내역과 잔액) · **상점**(분류별, 공동구매 함께 모으기) · **은행**(내 신용 등급 이자율로 예금, 만기면 원금+이자, 중도 해지는 원금만) · **주식**(원하는 금액만큼 소수점 매수, 매도, 평가 손익) · **직업**(우리 반 직업과 맡은 친구)

### 돈이 안전한 이유 (보안 규칙)
- 돈·아이템·예금·주식이 바뀔 때마다 **활동 기록 한 줄**이 함께 저장되고, 보안 규칙이 **"이전 잔액 + 기록의 변동 = 새 잔액"** 인지 검사합니다.
- 학생이 직접 할 수 있는 일은 구매·사용·공동구매·예금·주식뿐이고, 각각 가격×개수, 재고, 보유 한도, 이자율(신용 등급), 만기, 주식 가격·수량, 거래 시간, 하루 거래 횟수를 규칙이 다시 계산해 확인합니다. 잔액이 모자라면 거부됩니다.
- 여러 명이 동시에 거래해도 서버에서 더하기(increment)를 해 잔액이 꼬이지 않습니다.
- 학생은 **자기 계좌와 기록만** 볼 수 있습니다. 가격·직업·급여·신용 등급은 선생님만 바꿉니다.
- 데모 모드도 `database.rules.json`을 그대로 해석해 같은 규칙으로 검사합니다.

### 실제 주식 시세 (5~10분 간격)
GitHub Actions 예약 작업이 평일 장중에는 5분마다, 그 밖에는 1시간마다 네이버 증권·야후 파이낸스에서 시세를 받아 `prices` 브랜치의 `prices.json`에 올립니다(비밀 키 없음). **선생님 화면이 켜져 있는 동안** 그 시세를 Firebase에 저장하고, 시세가 30분 넘게 오래되면 실제 주식 거래는 잠시 멈춥니다. 실제 주식은 평일 장중(기본 09:00~15:30)에만, 학급 증권은 설정한 시간에 거래합니다.

**처음 한 번 켜기** — 예약 작업 파일 `tools/prices-workflow.yml`을 `.github/workflows/prices.yml`로 넣어야 합니다. 둘 중 하나:
- GitHub 저장소 웹에서 **Add file → Create new file** → 이름 `.github/workflows/prices.yml` → `tools/prices-workflow.yml` 내용을 붙여넣고 Commit
- 또는 명령 창에서 `gh auth refresh -h github.com -s workflow`로 권한을 준 뒤 파일을 복사해 push

※ GitHub는 60일 동안 저장소에 변화가 없으면 예약 작업을 멈출 수 있어요. 시세가 멈추면 저장소의 Actions 탭에서 「주식 시세」를 다시 켜 주세요.

### 아바타 상점
학생 「상점 → 🙂 아바타 상점」에서 모양(엄지·이모지·큰 웃음·로봇·픽셀 등)마다 **날마다 바뀌는 얼굴 후보**를 보고 돈으로 삽니다. 산 아바타는 「내 아바타」에 모이고 언제든 바꿔 쓸 수 있어요(기본 아바타 포함). 모양별 가격·판매 여부·후보 수는 「경제 설정 → 아바타 상점」에서 정합니다. 가격은 보안 규칙이 선생님 설정과 맞는지 확인합니다. (그림: DiceBear)

### 수페에서 가져오기
1. 수페 데이터를 담은 `soopeh-export.json`(이 컴퓨터의 `문서\class-tier-migration` 폴더, **GitHub에는 올리지 않음**)을 「관리 → 수페에서 가져오기」에서 고릅니다.
2. 학생은 **이름**으로 짝을 맞춥니다. 아직 계정이 없는 학생은 「이 학생들 계정 만들기」로 한 번에 만듭니다(아이디 `s01`…, 비밀번호는 「학생 관리」에서 확인).
3. 가져오기: 상점 13·직업 9(선생님 전용 「왕」 제외)·증권 5·퀘스트 6·은행/거래 설정과 학생별 잔액(마이너스 포함)·예금(만기 그대로)·주식(수량·투자금)·아이템·직업·신용 등급·아바타·퀘스트 완료 기록.
4. 같은 이름의 상품·직업·증권·퀘스트는 새로 만들지 않고 고치므로 여러 번 가져와도 겹치지 않습니다. 단, 학생 잔액·예금·주식·아이템은 **파일 값으로 다시 맞춰집니다**.
- 총자산은 주식을 **지금 가격**으로 계산해서 수페(산 가격 기준)와 조금 다를 수 있어요.

## 6. 퀘스트 (🎯)

| | |
|---|---|
| **선생님 → 퀘스트 관리** | 퀘스트 만들기: 보상(돈 + 아이템), 반복(**한 번 / 매일(요일 선택) / 매주**), 인증 방법(**확인만 / 글 / 사진**), 정원(기간마다 먼저 N명), 기간(시작·종료일), 대상 학생. 현황(이번 기간 누가 완료했는지, 요청 없이 바로 「완료 처리·보상」), 오래된 인증 사진 정리 |
| **선생님 → 확인 요청** | 학생의 완료 요청(글·사진 인증 보기)을 **승인하면 보상이 바로 지급**, 반려하면 사유가 학생에게 보임. 여러 개 한꺼번에 승인 |
| **학생** | 할 수 있는 퀘스트 / 완료 / 전체, 「완료 요청」(글 쓰기·사진 올리기), 요청 취소, 반려되면 다시 요청 |

- 학생은 「요청」만 쓸 수 있고 완료·보상은 선생님만 정합니다. 기간·요일·대상·정원·인증 방법은 보안 규칙이 다시 확인합니다.
- 인증 사진은 작게 줄여(약 100KB 이하) 저장합니다. Firebase 무료 용량(1GB)을 위해 가끔 「오래된 인증 사진 정리」를 눌러 주세요.
- 수페 퀘스트 6개와 학생별 완료 기록도 「수페에서 가져오기」로 옮겨집니다.

## 7. 판 (📌) — 자유 판 + 글쓰기 판

**자유 판** (패들렛처럼): 배치(모눈·칸 나누기·목록), 배경, 게시물 색·사진, 반응(👍❤️😮😂👏)·댓글, 고정, **선생님이 확인한 뒤 공개**(확인 전 글은 쓴 학생과 선생님만 봄), 학생 글쓰기 잠금, 대상 학생, 참여 인원(x/21). 학생은 자기 글만 고치고 지울 수 있어요.

**글쓰기 판** (수페 「주제 글쓰기」를 판에 합침):
- 선생님이 **주제와 일정**(시작·마감 시각, 기본 오늘 09:00~23:59), 안내, 최소 글자 수, 사진 허용, **통과 보상**, 대상을 정합니다. 상태: 예정 · 진행 중 · 마감.
- 학생은 주제마다 한 편을 쓰고, 선생님이 **통과**(보상 지급) 또는 **다시 쓰기**(의견)를 줍니다. 다시 쓰기면 의견을 보고 고쳐 다시 제출해요. 마감이 지나면 쓸 수 없어요.
- 주제별 현황(통과·확인 대기·다시 쓰기·안 씀), **학생별 모아보기**, 「통과한 글을 친구들도 보기」 선택.

## 8. 설치

1. **데모로 체험**: `.\serve.ps1` 실행 → `http://localhost:8767` (Firebase 없이 이 브라우저에만 저장)
2. **Firebase** (오목 아레나와 **별도 프로젝트**): Authentication 로그인 방법에서 **이메일/비밀번호**와 **Google** 사용 설정 → Realtime Database 생성(싱가포르) → 규칙 탭에 `database.rules.json` 게시 → 웹 앱 등록 후 설정값을 `js/firebase-config.js`에 입력
3. **GitHub Pages**에 올리고, Firebase Authentication → 설정 → **승인된 도메인**에 `아이디.github.io` 추가 (Google 로그인에 필요)
4. 처음 접속 → 선생님 계정(아이디 `teacher`) 만들기 → 학생 등록

css/econ.css            학급 경제 화면 디자인

js/hanja.js             한자 150자 자료 (훈음·대표 한자어)

js/econ-teacher.js      선생님 경제 화면 (학급 홈·상점·직업·급여·재테크·기록·통계·설정)
js/importer.js          수페에서 가져오기
