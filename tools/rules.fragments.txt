# tools/build-rules.ps1 이 rules.template.json 의 {{이름}} 을 아래 조각으로 바꿔 database.rules.json 을 만듭니다.
# "@이름" 줄 다음부터 다음 "@" 줄 전까지가 한 조각 (여러 줄은 공백으로 이어 붙임). "#" 으로 시작하는 줄은 설명.

# 돈이 움직이는 원리
#  - 돈·아이템·예금·주식이 바뀔 때마다 활동 기록(feed) 한 줄을 새로 쓰고, 계좌의 last 를 그 기록으로 바꿉니다.
#  - 잔액은 "이전 잔액 + 기록의 변동(a)" 이어야 하고, 기록을 쓰면 잔액도 반드시 그만큼 바뀌어야 합니다.
#  - 학생이 직접 쓰는 기록(구매·사용·공동구매·예금·주식)은 종류마다 조건을 검사하고,
#    아이템 개수·재고·예금·보유 주식처럼 함께 바뀌는 곳은 그곳의 규칙이 계산이 맞는지 다시 검사합니다.
